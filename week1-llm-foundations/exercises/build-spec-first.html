Spec first, then let the agent code

You write down what “done” means before any AI touches the code. Then an agent plans, you approve, it builds, and your checks decide whether it worked.

  • Whenafter the live demo, about 12:25
  • Filesspecs/triage_cli.md · AI-NOTES.md (you create it)
  • ToolsClaude Code through claude-class, or Copilot
You own the diff
“The AI wrote it” is not a defence.
Let it drive on boilerplate, glue and tests you can read. Check API details, cost maths, security and prompt logic against the docs and a real run.
  1. 1

    Write the spec

    Open specs/triage_cli.md and replace every <!-- … --> hint with your own words: what it does, the input, the output, and two acceptance checks you'll run yourself. The constraints are already written:

    specs/triage_cli.md
    ## Constraints
- Loads the prompt from prompts/extract_ticket.md (no inline prompt string)
- Reads the API key from the environment (never hard-coded)
- Uses claude-haiku-5-5
    ExpectedNo hints left in the file, and two checks you could hand to a stranger.
  2. 2

    Commit the spec

    A clean starting point, so you can see exactly what the agent changes.

    Terminal
    git add specs/triage_cli.md
git commit -m "spec: triage CLI"
    Expectedgit status says the working tree is clean.
  3. 3

    Ask Claude Code for a plan

    Start Claude Code on the class key, already in plan mode:

    PowerShell
    .\claude-class.cmd --permission-mode plan
    Terminal
    bash claude-class.sh --permission-mode plan

    Already in a session? Press Shift+Tab until the status bar shows ⏸ plan mode on. Then ask:

    Inside Claude Code
    Read specs/triage_cli.md and plan how to build the triage CLI it describes. Reuse load_prompt and triage from lab3_prompt_as_spec.py.
    ExpectedA plan: which files it will create or change, and how it will meet your checks. Nothing on disk has changed yet.
  4. 4

    Correct the plan, then approve it

    Read the plan as if a new hire wrote it. Does it meet your spec? Does it invent anything? Ask for one correction in plain words, then approve when it asks.

    Once it's building, it asks before creating files or running commands. Read each request before you allow it.

    ExpectedYou can name the one thing you changed in the plan, and a triage script now exists.
  5. 5

    Or hand the spec to Copilot

    OR

    Prefer Copilot, or want the side-by-side? Open Copilot Chat in VS Code, add specs/triage_cli.md as context, and ask it to build the CLI the spec describes. Then carry on from step 6 with its code.

    ExpectedA triage script from Copilot, held to the same spec and the same checks.
  6. 6

    Run your checks

    Run your two acceptance checks, exactly as you wrote them in the spec: not the agent's tests, and not its claims. For example:

    Terminal
    uv run triage.py "Export button throws 500 for all paid users"

    Your file name may differ. Use the one the agent created.

    ExpectedEach check clearly passes or fails, and you know which.
  7. 7

    Review what it changed

    Terminal
    git status
git diff
    ExpectedYou know every file it touched. Anything it changed that you didn't ask for goes in step 8.
  8. 8

    Log the truth in AI-NOTES.md

    Create AI-NOTES.md in the repo folder and fill it in honestly:

    AI-NOTES.md
    # AI-NOTES: Week 1 triage CLI

Tool: Claude Code (plan mode) / Copilot
Spec: specs/triage_cli.md

## What it got right
-

## What it got wrong
-

## How I caught it
-
    ExpectedAt least one thing it got right and one it got wrong. That's checkpoint item 3.
  9. 9

    Commit your work

    Terminal
    git status
git add -A
git commit -m "triage CLI built from spec, plus AI-NOTES"

    Check git status before you add: .env must not be listed. The repo's .gitignore keeps it out.

    ExpectedThe CLI and AI-NOTES.md in one commit, and no .env.

If something goes wrong

Claude Code says “No .env file here”, or asks you to log in

Start it with the launcher from the repo folder (setup step 10). If it still ignores the key, run /config inside Claude Code and switch on Use custom API key.

Plan mode doesn't appear

Shift+Tab cycles through modes; keep pressing until the status bar shows ⏸ plan mode on. Or quit with /exit and start again with --permission-mode plan.

It started editing before you approved a plan

It wasn't in plan mode. Press Esc to stop it, then look at git diff. Because you committed the spec in step 2, git restore . puts every tracked file back to that point.

One of your checks fails

Good: that's what the checks are for. Don't fix it by hand first. Paste the failing output to the agent, ask for a fix, and run your check again. Then write it up in AI-NOTES.md.

RateLimitError (429)

Ten agents are working at once. Wait 20 seconds and carry on.

Copilot says you don't have access

Your employer's settings may block it. Claude Code alone is enough today.

Checkpoint item 3 lives here

The triage CLI built from your spec with AI help, and AI-NOTES.md naming at least one thing it got right and one it got wrong.
