Quick check

Answer in your head or on paper first, then open the answer. Not graded. If one surprises you, ask in the cohort WhatsApp group.

  1. What does print(type(0.5)) show?

    Answer

    <class 'float'>: a number with a decimal point.

  2. x = [10, 20, 30]. What is x[1]?

    Answer

    20. Counting starts at 0.

  3. d = {"a": 1}. What does d.get("b", 0) give, and what happens with d["b"]?

    Answer

    0, the default. d["b"] stops with a KeyError, because there's no label "b".

  4. def double(n): return n * 2. What does print(double(4)) show?

    Answer

    8.

  5. Which lines belong to an if or a for?

    Answer

    The indented lines directly under it. The line above them ends with a colon.

If something goes wrong

“No such file or directory” or FileNotFoundError

You're in the wrong folder. Run cd AIEngineeringLab/week1-llm-foundations from where you cloned the repo, or cd .. if you're inside python_basics.

SyntaxError or IndentationError after your change

Check that every quote and bracket you opened is closed, and that indented lines use four spaces. Can't find it? git restore python_basics/ and try the change again.

NameError: name '…' is not defined

A name is misspelt, or used before the line that sets it. Python is case-sensitive: Name and name are different.

Your output doesn't match “What you'll see”

Did you already make the change? Then it shouldn't match. Otherwise, check you saved the file and ran the lesson with the right number.

“uv” is not recognized

Go back to setup step 4, then close and reopen VS Code.
