Set up your laptop

About 40 minutes, once. On Saturday we start typing at 10:23, so everything here has to work before you arrive.

Work top to bottom and tick each step as you finish it. The switch at the top shows commands for Windows or macOS. Steps 1–11 are needed on Saturday; step 12 is for Week 4, but it's quicker to do it now.

  1. 1

    Check your laptop

    You need Windows 10 (version 1809 or later) or 11, or macOS 13 or later, with 8 GB of RAM or more.

    Bringing a work laptop? Two things often get in the way: installs that need IT approval, and a VPN or proxy that blocks the AI services. If either applies, bring a personal laptop if you can. If you can't, tell us now and we'll set you up on GitHub Codespaces, which runs in the browser.

    ExpectedYou know which laptop you'll bring, and that you can install software on it.

    Install Git

    Download the 64-bit installer from git-scm.com/downloads/win and run it with every option left at its default. It also gives Claude Code a Bash shell to work in.

    macOS ships Git with Apple's command-line tools. Run the check below; if macOS offers to install the tools, accept, wait, and run it again.

    Open a new terminal and check it:

    Terminal
    git --version

    Then tell Git who you are. It writes this on every commit:

    Terminal
    git config --global user.name "Your Name"
git config --global user.email "you@example.com"
    Expectedgit version 2.…, and the two config commands print nothing.

    Terminal
    uv --version
    Expecteduv 0.… with a version number.

If something goes wrong

“not recognized” or “command not found” for git, uv, code or claude

Close every terminal, and VS Code, then open a new one. Installers only update new windows.

Still failing for uv or claude? Both install into your .local\bin folder. Add it to your PATH, then open a new terminal:

Still failing for uv or claude? Both install into ~/.local/bin. Add it to your PATH:

PowerShell
[Environment]::SetEnvironmentVariable("PATH", "$env:PATH;$env:USERPROFILE\.local\bin", "User")
Terminal
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
“running scripts is disabled on this system” (PowerShell)

Windows is blocking a script. Use the commands exactly as shown above: the uv installer runs with -ExecutionPolicy ByPass, and on Windows we call npx.cmd, not npx. The class launcher is a .cmd file, so it isn't affected.

AuthenticationError … 401 … invalid x-api-key

The key in .env is missing or wrong. Check it still doesn't say sk-ant-REPLACE_ME, and that there are no quotes or spaces around it. Save the file and run the command again.

Timeouts, “connection refused”, or SSL/certificate errors

Usually a work VPN, proxy or firewall. Try once off the VPN or on a home or phone network. If that works, the network is the problem: post in the cohort chat and we'll plan a Codespace for you on Saturday.

uv can't download Python

Behind some networks uv can't fetch Python itself. Install Python 3.12 from python.org (on Windows tick Add Python to PATH), then run the smoke test again.

Claude Code asks you to log in instead of using the key

You probably started plain claude. Start it with the launcher from the repo folder instead (step 10). If it still ignores the key, run /config inside Claude Code and switch on Use custom API key.

“No .env file here” from the launcher

You're in the wrong folder, or you skipped step 7. Run cd AIEngineeringLab/week1-llm-foundations and check that .env is there.

The Node.js installer asks for an administrator password

Cancel it and skip step 12 for now. On a work laptop, ask IT for Node.js LTS (x64). You need it by Week 4, not Saturday.

Copilot says you don't have access

Your employer's GitHub settings may block it. That's fine: Claude Code (step 10) is enough for Saturday.
