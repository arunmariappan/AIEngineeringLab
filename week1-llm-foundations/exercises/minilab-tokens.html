Same sentence, four languages

The model doesn't read words; it reads tokens, and you pay per token. How many does one sentence cost in English, Hindi, Kannada and Tamil?

Measure, don't assume
Billed in tokens. Limited in tokens.
Research on GPT-4's tokenizer found Indian languages averaged about 8× English's tokens for the same meaning. Nobody has told you Claude's number, so you measure it.

If something goes wrong

The Indian-language text shows as boxes or question marks

That's only your terminal's font. The counts are still right, and the ratios are what matter. VS Code's built-in terminal usually shows these scripts properly.

UnicodeEncodeError

Python is writing to a terminal that isn't set up for Unicode. Switch it on and run again:

PowerShell
$env:PYTHONUTF8 = "1"
uv run tokens_minilab.py
Terminal
export PYTHONUTF8=1
uv run tokens_minilab.py
AuthenticationError … 401 … invalid x-api-key

Your .env still has the placeholder, or the key has quotes or spaces around it.

RateLimitError (429)

Ten people are counting at once. Wait 20 seconds and run it again.
