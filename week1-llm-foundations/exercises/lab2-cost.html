  3. 3

    Check the maths by hand

    Don't trust a number you can't reproduce. This is the whole pricing rule:

    lab2_cost.py
    PRICES = {
    "standard": {"input": 0.10, "output": 0.50},   # prompt up to 100K tokens
    "long":     {"input": 0.50, "output": 2.50},   # prompt over 100K tokens
}
    lab2_cost.py
    def cost_usd(input_tokens: int, output_tokens: int) -> float:
    """Dollar cost of one call. (Prompt length counts ALL input tokens - with
    prompt caching that includes cache reads and writes, which we don't use today.)"""
    tier = "long" if input_tokens > LONG_PROMPT_THRESHOLD else "standard"
    rate = PRICES[tier]
    return (input_tokens / 1_000_000) * rate["input"] + (output_tokens / 1_000_000) * rate["output"]

    With your numbers: input ÷ 1,000,000 × 0.10 + output ÷ 1,000,000 × 0.50.

    ExpectedYour hand calculation matches cost this call.

  7. 7

    Price a Week 3 question

    STRETCH

    Your Week 3 RAG app makes 5 calls per question, 10,000 questions a day. Each prompt carries 120K tokens of retrieved text. What does the input alone cost per month? Now try it with 20K tokens.

    Check your answer

    120K is over the cliff: 120,000 ÷ 1M × $0.50 = $0.06 per call × 1.5M calls = $90,000 a month. At 20K: 20,000 ÷ 1M × $0.10 = $0.002 × 1.5M = $3,000 a month. Six times the text, thirty times the bill.

    ExpectedTwo monthly figures, and an opinion on how much text a prompt should carry.
