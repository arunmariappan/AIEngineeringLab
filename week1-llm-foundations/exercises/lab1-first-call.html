Run it, read it, change it

Your first LLM call from code. You'll see the same prompt give different answers, read the code that made the call, and change it to ask something from your own job.

  • When10:40–11:00
  • Filelab1_first_call.py
  • Modelclaude-haiku-5-5
The one thing to notice
Same input, unpredictable output
Usually three different taglines, sometimes a repeat, and you can't predict which. There's no setting on this model that makes it stop. So from Week 2, we stop eyeballing and start measuring.
  1. 1

    Open the repo and a terminal

    RUN

    In VS Code, open the week1-llm-foundations folder, then Terminal › New Terminal. Your key should be in .env (setup step 7).

    ExpectedThe terminal prompt ends in week1-llm-foundations.
  2. 2

    Run the same prompt three times

    RUN

    Part 1 asks for a one-sentence tagline for a cold-brew coffee shop, three times, with exactly the same prompt. Part 2 asks one question at three effort levels.

    Terminal
    uv run lab1_first_call.py

    Before you scroll on: how many different answers did you get? Compare with your neighbour.

    ExpectedThree taglines: usually all different, sometimes two match. Either way you couldn't have predicted which. That's the point: the same input doesn't promise the same output.
  3. 3

    Read it: find three things

    READ

    Open lab1_first_call.py. First, the prompt, marked # CHANGE ME:

    lab1_first_call.py
    # CHANGE ME (Lab 1, step 4): swap this prompt for one from your job, e.g.
#   "Summarise this alert in one line: disk usage on db-01 is 91% and rising."
tagline = "Give me a one-sentence tagline for a coffee shop that only sells cold brew."

    Second, ask(): the call from the slides. max_tokens is one ceiling for thinking and answer together:

    lab1_first_call.py
    message = client.messages.create(
    model=MODEL,
    max_tokens=1024,                     # a CEILING for thinking + answer together, not a target
    output_config={"effort": effort},    # low | medium | high | xhigh | max
    messages=[{"role": "user", "content": prompt}],
)

    Third, the line that picks the answer out of the reply. A reply is a list of blocks, and this model thinks by default, so the first block can be a thinking block:

    lab1_first_call.py
    def text_of(message) -> str:
    """A response is a LIST of content blocks, not a string.

    Haiku 5.5 thinks by default, so the first block can be a `thinking`
    block. Pick the text blocks by their type, never by position.
    """
    return "".join(block.text for block in message.content if block.type == "text")
    ExpectedYou can say why message.content[0].text would break on this model.
  4. 4

    Change it: a prompt from your job

    CHANGE

    Replace the tagline prompt with one from your own work, save, and run again. Some ideas:

    • Ops / SRE: Summarise this alert in one line: disk usage on db-01 is 91% and rising.
    • Support: Write a polite one-line reply to: “my invoice shows the wrong amount”.
    • Cloud: In one sentence, what is an Azure resource group for?
    • Hardware: In one sentence, what does a pull-up resistor do?
    Terminal
    uv run lab1_first_call.py
    ExpectedUsually different answers to your prompt too. Same input, output you can't predict.
  5. 5

    Compare low and high effort

    CHANGE

    Part 2 asks one everyday question (a tea-stall bill) at low, medium and high effort. Effort sets how hard the model may think, not how random it is. Write down what you see:

    effortthinking tokenssecondsanswer
    low
    medium
    high
    Check the arithmetic (try it yourself first)

    If all 13 were teas the bill would be ₹195. The extra ₹50 comes from coffees, each ₹10 dearer than a tea: so 5 coffees (and 8 teas). Check: 8 × ₹15 + 5 × ₹25 = ₹245.

    ExpectedThree --- effort=… lines showing output tokens, (thinking …) and seconds, each ending stop_reason=end_turn. Higher effort lets the model think harder; it doesn't force it. With one run at each level the numbers bounce around and can even go backwards (a test run gave 145, 119 and 182 thinking tokens). To know whether high effort is worth paying for, you'd measure many runs: that's Week 2. Thinking is billed as output, so it shows up in the bill too.
  6. 6

    Try to pin it down: temperature

    EXTEND

    Older models had a temperature dial. Add temperature=0, as a new line inside the client.messages.create( call, save, and run again:

    Terminal

    Read the error, then take the line out again.

    ExpectedTypeError: Messages.create() got an unexpected keyword argument 'temperature', raised before anything is sent. On this model you can't opt out of variance.

    Starve it of tokens

    EXTEND

    ExpectedShort, cut-off or empty answers, and stop_reason=max_tokens: thinking and answer share one budget, and it ran out.

    Ask a chat app the same thing

    EXTEND

Quick check

Answer in your head or on paper first, then open the answer. Not graded. If one surprises you, ask in the cohort WhatsApp group.

  1. You ran the same prompt three times and got three answers. Is that a bug?

    Answer

    No. The model picks from likely next words with some chance. You measure it instead of expecting the same text: that's Week 2.

  2. Why does every lab pick text blocks by type instead of reading message.content[0].text?

    Answer

    Haiku 5.5 thinks by default, so the first block can be a thinking block, which holds no answer.

  3. max_tokens=1024: what exactly does it limit?

    Answer

    The most tokens the model may write back, thinking and answer together. A ceiling, not a target.

If something goes wrong

AuthenticationError … 401 … invalid x-api-key

Your .env still has the placeholder, or the key has quotes or spaces around it. Fix it, save, and run again.

ModuleNotFoundError: No module named 'anthropic'

You ran python outside the project's environment. Use uv run lab1_first_call.py, which uses the right environment every time.

RateLimitError (429) or overloaded (529)

Ten people are calling at once. Wait 20 seconds and run it again. Nothing is wrong with your code.

A run prints nothing where the answer should be

The answer ran out of room after thinking. Check that max_tokens is still 1024.

SyntaxError after your change

Your prompt needs a quote at each end, and no extra quote inside. Copy the original line's shape, or git restore lab1_first_call.py to start again.

“uv” is not recognized

Go back to the setup page, step 4, then close and reopen VS Code.
