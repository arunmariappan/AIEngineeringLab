Version your prompt

You are a support-ticket triage assistant.
Read the ticket inside the <ticket> tags and return exactly these three lines, nothing else:

priority: one of [low, medium, high, urgent]
category: one of [bug, feature-request, question, billing]
summary: one sentence, max 15 words

If the ticket doesn't contain enough information for a field, write "unknown"
rather than guessing.

    The script loads it and fills in {ticket} by plain replacement, not str.format, which would trip over any other braces, like the JSON examples you'll add in Week 2:

    lab3_prompt_as_spec.py
    def load_prompt(**values: str) -> str:
    """Load a versioned prompt file, drop '#' metadata lines, fill {placeholders}.

    Uses explicit replacement (not str.format) so JSON braces in a prompt never collide.
    """
    lines = PROMPT_FILE.read_text(encoding="utf-8").splitlines()
    body = "\n".join(line for line in lines if not line.startswith("#"))
    for key, value in values.items():
        body = body.replace("{" + key + "}", value)
    return body
    ExpectedYou can point at the version line, the {ticket} placeholder, and the “write unknown” line.

If something goes wrong

FileNotFoundError: prompts/extract_ticket.md, or ModuleNotFoundError: lab3_prompt_as_spec

Run it from the Week 1 folder: cd AIEngineeringLab/week1-llm-foundations first.

“Author identity unknown” when you commit

Git doesn't know who you are yet. Do setup step 2, then commit again.

git diff shows nothing

Save the file first: VS Code shows a dot on the tab of an unsaved file. If you've already committed, git log -p -1 shows the last change.

The output has extra text, markdown, or an explanation

The model didn't follow “nothing else”. Note it. Week 2 forces the shape with structured outputs.
